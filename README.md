# AgentTrace

AgentTrace is an open-source visual debugger for agentic workflows. It acts as a "flight data recorder" for your AI agents, synchronizing execution state (like UI screenshots or DOM state) with the exact LLM prompt and response.

## Features

- **TypeScript Interceptor SDK**: A lightweight library (`@agent-trace/sdk`) to log LLM calls, tool executions, and environment state into a standardized `.jsonl` trace file.
- **Visualizer Dashboard**: A local Vite + React dashboard that reads your trace files and provides a Timeline Scrubber to chronologically replay an agent's execution.
- **Environment & AI Split-View**: Instantly see what the agent "saw" (via DOM snapshots) next to what it "thought" (system prompts, user prompts, responses, and tool calls).

---

## 1. Using the SDK

The SDK allows you to record trace events from your own agents.

### Installation

```bash
cd packages/sdk-ts
npm install
```

### Quick Start

Wrap your agent's execution loop with the `AgentTracer`:

```typescript
import { AgentTracer } from '@agent-trace/sdk';

const tracer = new AgentTracer({
  agentId: 'my-browser-agent',
  // outputDir: './.agent_traces' (default)
});

// Log an event
tracer.logEvent(
  'llm_call',
  { url: 'https://example.com', domSnapshot: '<html>...</html>' },
  {
    systemPrompt: 'You are an agent.',
    userPrompt: 'What is on this page?',
    response: 'I will click the button.'
  },
  [{ name: 'click_button', arguments: { selector: '#submit' } }]
);
```

---

## 2. Running the Visualizer Dashboard

The visualizer provides a sleek UI to replay the traces generated by the SDK.

### Starting the Dashboard

```bash
cd visualizer
npm install
npm run dev
```

1. Open `http://localhost:5173` in your browser.
2. The dashboard will automatically load the trace data and allow you to scrub through the timeline!
